Версия уточняется…

Данные остаются у вас. Программа хранит всё в обычной папке на вашем диске: счета и настройки — в data.json, операции — по месяцам, заметки — в markdown. Ни учётных записей, ни сервера, ни отправки на сторону. Папку можно унести на флешке, положить в git или синхронизировать любым облаком — на ваше усмотрение.

Что внутри

  • Счета и операции — наличные, карты, копилки, кредиты и долги.
  • Бюджет по категориям с правилом 50/30/20.
  • Прогноз на год вперёд, с разбросом по методу Монте-Карло.
  • Проектные счета — чужие деньги на вашем счету не считаются вашим доходом.
  • Задачи с важностью, сроками и помидорами; задача с суммой попадает в прогноз.
  • Канвас и заметки — доска со связями и markdown рядом с цифрами.
  • Грамота — чины, ордена и знаки за порядок в деньгах.

Обновления

Установщик берётся один раз. Дальше в «Настройках» есть кнопка «Проверить обновление», и раз в сутки программа смотрит сама — молча, ничего не скачивая без вашего согласия.

Объявление об обновлении подписано ключом автора. Подменённый файл не установится, даже если взломают этот сайт: скачанное сверяется по подписи, размеру и контрольной сумме.

Браузерная проба

Ссылка «Открыть в браузере» показывает ту же программу без установки. Данные в ней лежат внутри браузера: между устройствами не ходят, а очистка истории сайта их стирает. Для настоящего учёта ставьте программу.
